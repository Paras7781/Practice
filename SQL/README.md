# SQL Examples Project

This workspace contains a small collection of Python scripts demonstrating:

- MySQL connection using the MySQL connector
- SQLite database usage
- SQLAlchemy ORM setup
- SQLite to MySQL data migration

## Folder structure

- src/ - Python example scripts
- data/ - SQLite database files
- docs/ - project notes and documentation

## Running examples

Run scripts from the project root using:

```bash
python src/pdbc_sqlite.py
python src/sqlalchemy_with_sqlite.py
python src/sqlite_to_mysql.py
```
